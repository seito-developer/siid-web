# scripts

プロジェクト運用用のスクリプト置き場。

## apng-to-webp.mjs — APNG をアニメーション WebP に変換する

アニメーション付き PNG(APNG)を、アニメーションを保ったまま WebP へ変換してファイルサイズを落とす(Issue #94)。

```bash
node scripts/apng-to-webp.mjs <入力.png> <出力.webp> [--size 400] [--quality 75] [--frame-step 2]
```

- `--size` 出力の一辺(px)。**実際の表示サイズ × デバイスピクセル比**を目安にする
- `--quality` 0〜100
- `--frame-step N` N 枚に 1 枚へ間引く。捨てたフレームの表示時間は残すフレームへ加算するので**再生時間は変わらない**。**サイズはフレーム数にほぼ比例するため、これが最も効く**

必要なコマンド: `ffmpeg`(フレーム展開)と `img2webp`(libwebp。組み立て)。
ffmpeg にアニメーション WebP のエンコーダが含まれない環境があるため、2 段構えにしている。

注意: `next/image` はアニメーション画像を最適化せず**素通し**する。`w=` を指定しても縮小されないため、
**元ファイル自体を適切な解像度にしておく**必要がある。
