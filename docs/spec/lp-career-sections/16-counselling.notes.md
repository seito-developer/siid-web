# 16. FREE COUNSELING — 補足

## 特徴カードを横1列にする（2026-09-15 / Issue #106）

ブラウザ確認で、予約CTAから移動してもフォームが見えないため、4つの四角い特徴カードを1列にして高さを縮めることがユーザーから指定された。

- PC/SPとも4枚を横1列に配置。参加費無料・60〜90分・オンライン・無理な勧誘なしの文言を維持する。
- 既存SP画像の256px角タイルをCSSの背景スプライトとして再利用し、80px角で表示する。画像の枠・アイコンはそのまま使い、HTMLのラベルを重ねる。
- 元の背景にある2段タイル・見本フォームが再表示されないよう、背景画像は上部だけをマスクで残し、セクションの暗色へなじませる。
- SPのカード位置はセクション上端から360px、フォームカードは454px（従来675pxから221px短縮）。フォームの高さは引き続き内容に追従する。
- PCは左カラムの幅342pxに4枚を配置。右カラムの予約フォームを維持する。
- SPの横幅に比例するキャンバス拡縮によりフォームが画面外へ出る場合は、`scroll-margin-top` を画面高と縮尺から計算してアンカー位置を調整する。`#counselling` のURLと埋め込みの処理は変更しない。
- 実フォームの日時選択画面まで読み込み確認。予約送信は行わない。
