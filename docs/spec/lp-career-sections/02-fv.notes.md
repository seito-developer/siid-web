# 02. FV — 補足(手書き)

## PSD の背景は動画の仮置きであり、そのまま実装してはいけない(決定済み)

> **ヒアリングでの決定**: 実際の動画とカンプが異なっても構わない。**動画を使う。**

`fv/video` グループの中身は **Zoom のギャラリービューのスクリーンショット**
(`スクリーンショット 2026-08-24 17.48.04` / 1440×774)で、その上に **受講生の顔を隠す
絵文字が 11 個**(112×112 と 115×115)貼られている。

一方、実際に支給された FV 動画 `fv-pc.mov` は **教室で講師が講義している別のカット**で、
Zoom のグリッドではない。受講生は後ろ姿で顔は写っていないため、絵文字による目隠しも不要。

したがって:

- **`fv/video` のスクリーンショットと 11 個の絵文字は実装しない。** 動画の仮置きである
- FV の背景は `public/videos/lp-career/fv-pc.mp4` / `fv-sp.mp4` を `<video>` で再生する
- **`fv/video/over`(1443×702 の暗いシェイプ)は実装する。** 白文字を読ませるためのスクリムで、
  動画に差し替えても必要
- グリッド構成が全画面のカットに変わるため、**FV の見え方はカンプと一致しない。これは承認済みの差分**。
  §13.1 / §13.2 の一致率判定では FV セクションだけこの差分が出るため、
  **FV は動画領域を除いた要素(コピー・バッジ・メダル・CTA・スクリム)の配置で判定する**。
  動画領域を含めた数値では合格ラインに届かないが、それは実装の誤りではない

## 要素ごとの実装方針

| 要素 | PSD 上のパス | 実装 |
|------|-------------|------|
| 背景動画 | `fv/video` | `<video autoplay muted loop playsinline poster>` |
| 暗いスクリム | `fv/video/over` | CSS(半透明の重ね) |
| メインコピー | `fv/main` | テキスト(`h1`) |
| 上部ラベル | `fv/Al × PROGRAMMING × CAREER` | テキスト。**`Al` ではなく `AI`**(PSD の字形が紛らわしいだけ) |
| 帯付きコピー 2 本 | `fv/元人事部長の`, `fv/学習から内定まで総合プロデュース` | シェイプは CSS、文字はテキスト |
| 経産省バッジ | `fv/card` | `fv-badge-card.webp` + テキスト |
| 実績メダル 3 個 | `fv/medal/1〜3` | `fv-medal.webp` を 3 回使い、数値はテキスト |
| メダルの発光 | `fv/medal/N/光` | CSS の `box-shadow` / `radial-gradient`。スクリーン合成のため画像化できない |
| CTA ボタン | `fv/btn` | シェイプと三角形は CSS / SVG、発光は CSS。画像不要 |
| CTA 帯の背景光 | `fv/cta_bg` | CSS のグラデーション |
| ヘッダー | `fv/header` | §01 参照 |

## ロゴは既存アセットを流用する

ヘッダーのロゴは PSD 上ではラスターレイヤー(`fv/header/レイヤー 22` / 125×31)だが、
等倍のため Retina では足りない。**既存の `public/images/lp-1/siid-logo.svg`(黒) と
`siid-logo-w.svg`(白) が同じ字形なのでこれを流用する。**
