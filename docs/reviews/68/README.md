# Issue #68 デザイン修正の確認記録

2026-09-08。PR #66 の実装を引き継ぎ、PSD と実画面の目視比較を基準に修正。

## 確認基準

無料フォントへの置換による字形差は許容し、配置・文字サイズ・配色・余白・装飾をカンプに合わせる。
一致率の数値だけでは合格としない。固定ヘッダーを含むPC/SP通し画像、開閉状態、中間幅を確認する。

## 修正

- セクションラベルの文字寸法・斜体・細線。背景に含まれる線の二重描画を除去。
- 見出しのグラデーションと黄／白の強調、本文のサイズと折り返し。
- SKILLSの固定幅タグ、カード配置、SP開閉に伴う後続カードの移動。
- DIFFERENCEの表の列・行・罫線、当社見出しの段差、POINT番号。
- RESULTSの両端画像欠落と、説明文によるSP矢印クリックの遮断。
- PRICING・VOICE・PRESENTの文字位置、FAQとVOICEの展開時の高さ。
- PCのFV回路帯とCTA画像。ボタンの読ませる文字はHTMLを維持。
- 設計幅375/1440からの等比拡縮。1440px超の中央配置、未対応ブラウザ向け補完。
- Jicooの実フォームを不透明なカードに配置し、外部iframeの高さ変化に追従。
- 撮影時にフォントを待ち、撮影画像と同時点のDOM座標を同じディレクトリへ保存。

## 確認の制約

- この検証環境ではJicooの空き日程APIがCORSエラーとなった。iframeの挿入と高さ更新、
  ページレイアウトは確認できたが、実際の空き日程選択・予約送信は検証していない。
  通し画像では画面外iframeが白く撮影されることがあるため、表示の合否はフォーム位置へスクロールして確認する。
- 本番ビルドには変更対象外の404用Phaserの既存import警告が出る。
- ローカルにはmicroCMS環境変数を設定していないため、ニュースの外部データ取得は検証対象外。
- 既定のFV動画、無料フォント、仮キャプション、別IssueのCV計測、公開後の確認事項は引き継ぎの判断を維持。
